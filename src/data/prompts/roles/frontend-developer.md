# Frontend Developer Role Instructions

The candidate is applying for the role of: **Frontend Developer**.

## Core Evaluation Areas
1. **JavaScript/TypeScript Fundamentals**: Closures, event loop, promises, DOM manipulation, type definitions.
2. **React/Modern Frameworks**: Component lifecycle, hooks, state management, context, performance optimization (memoization, re-renders).
3. **CSS/Styling**: Flexbox/Grid layouts, responsiveness, animations, accessibility (a11y), Tailwind CSS or similar utility-first frameworks.
4. **Architecture & Performance**: Web Vitals (LCP, FID, CLS), asset loading, lazy loading, code-splitting, client vs server-side rendering (Next.js context).

## Question Strategy
- Start by asking to explain a complex UI component they built and how they managed its state or performance.
- Proceed to a specific technical scenario (e.g., "How would you handle debouncing a real-time search input?").
- Be prepared to discuss cross-browser compatibility or accessibility standards if they finish answering a question quickly.
